              这个站是怎么做的

              一句话：这是一个纯前端的网页播放器，没有自己的后端，也没有数据库。页面在你的浏览器里跑，歌单和设置存在你自己的浏览器里，歌曲信息与播放地址则由一个很小的中转服务从网易云取回来。

              页面这一侧

              整站就三个文件：index.html、css/music-page.css、js/music-page.js。没有框架、没有打包步骤，浏览器直接跑源码，改完刷新就能看到效果，所以打开很快，也不会遇到"依赖装不上"这类问题。

              它做的事情其实很朴素：搜索拿到歌曲列表 → 取到播放地址塞进 <audio> → 用封面算出一套主题色 → 需要的时候再画大屏逐字歌词。

              你的歌单、主题、歌词偏移这些设置，全部存在浏览器的 localStorage 里。好处是不用注册、不会上传；代价是换台设备或清了缓存就没了——所以歌单提供了导出 / 导入 JSON 的入口。

              中转这一侧

              网页没法直接调网易云的接口，原因有两个：一是跨域，浏览器会拦掉；二是网易云网页版真正在用的接口是加密的，而那套明文的旧接口会按出口 IP 判断"境外"，然后直接回一个空结果。

              所以中间放了一个 Cloudflare Worker：它照着网易云网页版的做法做 weapi 加密（AES 两层加 RSA），拿到结果再以普通 JSON 交给页面。它只负责搜索、歌词、播放地址、歌单这类查询，自己不存数据；歌词还会在边缘节点缓存一小时，同一首歌第二次打开基本是瞬开。

              要注意音频本身并不经过 Worker。页面拿到的是网易云 CDN 的直链，声音是浏览器直接从那边拉的，这样中转不背带宽，拖动进度条也更快。

              歌词是别人的功劳

              那页会逐字高亮、带弹性滑动效果的歌词，用的是开源项目 AMLL（Apple Music-like Lyrics）——就是一个专门"把歌词做得像 Apple Music"的组件库。

              它单独放在 /vendor/ 下，约 390KB。进站之后会趁浏览器空闲的时候悄悄预先下好，不占首屏的带宽，等真的进大屏歌词就不用等了；开了省流量模式或者只有 2G 的话会跳过，等你要看时才下。

              另有几处是浏览器自带能力，没有额外依赖：锁屏和通知栏的控制走 MediaSession，主题色由 CSS 的 oklch() 动态算出来。

              边界与声明

              • 本站不存储、不转存任何音频文件，播放的歌曲都来自网易云音乐，版权归原作者与平台所有。
              • 仅供个人学习与自用，请不要公开传播或用于商业用途。
              • 接口随时可能因为平台调整而失效，那属于正常现象，不代表网站坏了。
              • 密码登录是这个小站自己的一道门，账号表放在 Worker 里，和网易云账号无关；扫码登录用的是你自己的网易云凭证，只保存在这台浏览器，换设备要重新扫。
